# PHP-Image-Directory-Browser
A lightweight, standalone PHP script to browse and inspect images in a web directory.
PHP Image Directory Browser automatically scans the directory where it is installed and displays all image files in a clean, responsive HTML table.

For each image, it provides a thumbnail preview, filename, resolution, file size, format, MIME type, and a direct link to the original file.

*Features*
- Supports JPG, JPEG, PNG, GIF, WebP, SVG, AVIF, BMP, TIFF, and ICO.
- Displays image thumbnails and technical information.
- Shows file sizes in KB or MB.
- Sortable file listing.
- Responsive interface for desktop and mobile.
- No database, external libraries, or configuration required.
- Read-only: does not modify or delete files.

*Installation:*

Simply upload images.php to any web-accessible directory and open it in your browser:

https://example.com/images/images.php

The script automatically lists the images in that directory. No additional setup is needed.

*Requirements*

A PHP-enabled web server with PHP 7.4 or later.
